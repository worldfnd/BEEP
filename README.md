

# BEEP: Better Elimination of Pretenders

Folder contents:
- paper: the BEEP paper
- lean: formalization of the main theorem (Theorem 3.4) of the paper, and of its analogous affine version (Theorem 5.3).
- beep-ligerito: a minimal modification of Ligerito's implementation from the Flock repository (https://github.com/succinctlabs/flock) that includes DEEP sampling
